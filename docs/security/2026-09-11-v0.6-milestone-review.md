# Security Review — V0.6 "Organize Your Own Folders", as Built

- Date: 2026-09-11
- Scope: the whole milestone — the tidy permission, suggestions, AI on a real folder, tidying,
  undo, undo after reopening, interrupted tidies, Review in Organize, and the retirement of the
  practice page.
- Required by: the design's build order step 6 (`docs/superpowers/specs/2026-09-10-organize-your-own-folders-design.md`),
  which asks for a record that checks the built system against its threat design.
- Earlier reviews this one builds on: `2026-09-10-real-folder-ai-disclosure-review.md` (step 2b),
  `2026-09-10-real-folder-tidy-review.md` (step 3), `2026-09-11-tidy-recovery-review.md` (step 4).
- Status: accepted, with the residual risks below and the owner's manual checks outstanding.

## Method

Every row of the design's threat table, and every rule in its Part 2, was traced to the code that
enforces it and to a named automated test that fails without it. A row with no such test counted
as a gap even if the code looked right. For the controls added in this milestone, the control was
removed on purpose and the test was confirmed to fail (recorded in the step reviews and below).
All tests use generated files in owned temporary folders, with a sentinel file outside the folder
that must stay unchanged.

## Residual risks

- **Checked by hand only.** The WinUI dialogs (connect, Allow tidying, Ask AI's preview), the
  interrupted-tidy card, the notice, keyboard and screen-reader use, and light, dark, and high
  contrast are covered by `docs/MANUAL-TESTING.md`, not by automated tests. The view-model call
  behind each dialog is page-tested.
- **A real crash and a real second window.** Tests stop the real journal at chosen moments and
  hold the lock file from the test; ending DeskAI from Task Manager and running two windows are
  manual checks.
- **The last instant before a move.** Between the final check and `File.Move` a file could still
  be swapped. The move never overwrites, and moving a link moves the link, not what it points
  to, inside the folder; that small window is accepted.
- **Online-only detection** relies on Windows attributes. Cloud clients that mark files
  differently may not be caught when listing; a file that would need downloading fails or is
  moved as the client allows. Test with the owner's cloud client on generated files only.
- **"Already undone" looks at the latest 100 journal records.** A partly undone tidy older than
  that could be offered to undo again through the executor. The page only ever offers the latest
  tidy, and every file still gets undo's own checks, so the effect is at worst a second attempt
  that refuses per file. Worth tightening when the journal gains a retention policy.
- **History is kept until disconnect.** The journal holds names of files in tidied folders with no
  retention limit; disconnecting erases it. A retention setting is future work.
- **Leftovers from the retired practice page** — old temp folders under `DeskAI-Demos` and their
  journal records — are left untouched rather than deleted by an update.

## Not accepted by this milestone

Deleting or sending anything to the Recycle Bin; moving files out of the chosen folder or out of
subfolders; renaming except the " (2)" a person chose; automatic checks moving anything; running
while DeskAI's window is closed; undoing any tidy but the last; confirming duplicates by content.
